# am-oss-hq

Open source work by [Alfred Mouelle](https://alfredmouelle.com): developer tools built for real projects first, then shared.

## What you will find here

- Developer tools, CLIs and libraries, mostly in TypeScript.
- Project starters and templates.
- Packages published on npm under [`@am-oss`](https://www.npmjs.com/org/am-oss).

Browse the repositories below; the pinned ones are the most active.

## Principles

- Built for a real need and used in production before release.
- Small and focused: one problem per project, solved well.
- No lock-in: open formats, documented behavior, easy to leave.
- Documented for humans and for AI agents alike.
