# Contributing

Thanks for your interest. These guidelines apply to every repository in this organization unless the repository has its own `CONTRIBUTING.md`.

## Before you start

- For a bug, open an issue with the steps to reproduce, the expected result and the actual result.
- For a feature or a larger change, open an issue first to agree on the approach before writing code.
- For a security problem, follow `SECURITY.md` instead of opening an issue.

## Pull requests

- Keep each pull request focused on one change.
- Follow the repository's existing style; run its checks (typecheck, lint, tests) before pushing.
- Add or update tests for behavior you change.
- Write code, comments and commit messages in English.
- Describe what changed and why in the pull request.
