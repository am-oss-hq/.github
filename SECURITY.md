# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: open the affected repository, go to the **Security** tab and choose **Report a vulnerability**. Include what you found, how to reproduce it and the versions affected.

You will get an acknowledgment within 3 business days and an assessment within 10 business days. Once a fix is released, the report is disclosed in a security advisory, credited to you unless you prefer otherwise.

## Supported versions

Only the latest release of each project receives security fixes, unless its own `SECURITY.md` says otherwise.
